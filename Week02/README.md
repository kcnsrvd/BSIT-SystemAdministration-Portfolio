# Week 02 – Enterprise IT Infrastructure Plan

## Project Overview

This project presents an IT Infrastructure Plan for **ABC Startup Solutions**, a fictional software development company with 20 employees.

The plan includes the company's hardware, software, network equipment, network topology, system administration roles, security recommendations, backup strategy, and future expansion plan.

## Learning Objectives

Through this project, I learned how to:

* Plan IT infrastructure for a small company.
* Identify needed hardware and software.
* Create hardware and software inventories.
* Design a basic enterprise network.
* Understand different system administrator roles.
* Create professional IT documentation.
* Plan basic security, backup, and future expansion.

## Company Scenario

**ABC Startup Solutions** is a newly established software development company located in Santa Rosa City, Laguna.

The company has **20 employees** divided into four departments:

| Department             | Employees |
| ---------------------- | --------: |
| Information Technology |         5 |
| Human Resources        |         4 |
| Finance                |         5 |
| Sales                  |         6 |
| **Total**              |    **20** |

The company currently has no computers, server, network, internet infrastructure, or security policies. This project provides a complete starting IT infrastructure for the company.

## 💭 Reflection
This project helped me to understand that system administration is not totally about how they are going to fix the computers in a company. A system administrator should firstly need to know and understand the needs of the organization and then carefully plan on how they’re going to configure the network and manage the servers, software, hardware, and security. This activity helps me to understand how important it is to have a transparent record or inventory of the devices, hardware, software, and network. I have gained knowledge on how to plan an IT infrastructure of a newly established startup company. 
One of the most challenging tasks for me was to make an enterprise network topology because I really don’t know how to connect them because you need to think and plan carefully on how and where you are going to connect each device. 
Planning before deployment is important because it can prevent errors or issues immediately. Because if you deploy first without planning, it may lead to security problems, expenses that are not needed, the network might have issues and can perform poorly eventually, and also it might not be scalable and cannot handle the growth of the organization. Planning can help to strategize the solutions to problems that may occur. It makes the future maintenance and troubleshooting to be easier.
This project will help me to become a better System Administrator by improving my planning and problem-solving skills. It helps me to improve my critical thinking that can help me in the future. I realized that it is really important on how we need to consider and plan carefully about the company’s budget, requirements, security, and needs. I understand how important the roles of every department in an organization, and how they serve a purpose to make the company efficient, reliable, and trustworthy.
